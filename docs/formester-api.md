# Introduction to Formester API

Formester provides a powerful REST API for managing and analyzing form submissions. Our API allows you to interact with Formester programmatically, giving you access to your forms and submission data.

## Getting Started

- **For the API**: Visit [app.formester.com/api](https://app.formester.com/api) in your Formester dashboard to generate your token.
- **For MCP**: See the [MCP Server guide](./formester-mcp-server.md) to connect AI agents directly to your submissions.

> API v1 has been retired. Its endpoints and tokens no longer work. Use API v2 for all integrations.
